## Descripción del proyecto

Este proyecto consiste en el desarrollo de una calculadora en Java que permite realizar operaciones matemáticas básicas y avanzadas, incluyendo la resolución de ecuaciones cuadráticas, mediante una interfaz de consola con validación de entradas.

---

## Aporte de Jonathan Manquel

Se encargó de la **implementación de la lógica de operaciones matemáticas (Opción 2)**, desarrollando clases separadas para mantener una estructura modular y ordenada.

### Operaciones básicas implementadas:

* Suma
* Resta
* Multiplicación
* División (con control de división por cero)

### Operaciones adicionales implementadas:

* Mayor de dos números
* Menor de dos números
* Potencia
* Cálculo de porcentaje

### Aspectos técnicos desarrollados:

* Creación de la clase `OperacionBasica` para operaciones aritméticas
* Creación de la clase `OperacionExtra` para operaciones complementarias
* Uso de métodos reutilizables para cada cálculo
* Manejo de errores mediante excepciones (`ArithmeticException`)
* Integración inicial de las operaciones en la clase principal `Calculadora`

## Pruebas unitarias

Se implementaron pruebas unitarias utilizando JUnit para validar el correcto funcionamiento de los métodos asociados a cálculos matemáticos, cumpliendo con el requisito de al menos 2 pruebas por método.
